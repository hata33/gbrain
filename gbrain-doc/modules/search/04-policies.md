# search — 策略与边界

> 搜索系统的排序策略、缓存策略和边界情况。

## 排序策略

### RRF 融合公式
```
score = Σ (1 / (k + rank))
k = 60（平衡头部和尾部结果）
```

### 加权优先级
1. **compiled_truth boost**（2.0x）— 综合真相版本优先
2. **图谱信号** — 关系密度高的实体优先
3. **时间衰减** — 最近的内容优先（可配置衰减速率）
4. **数据源加权** — 不同源可配置不同权重
5. **精确匹配** — 完全匹配的关键词额外加权

## 缓存策略

```
查询缓存（query-cache.ts）：
  → 缓存键：规范化后的查询字符串 + 搜索模式
  → TTL：可配置（默认 5 分钟）
  → 失效：内容更新时自动失效
  → 安全检查：query-cache-gate.ts 判断是否可缓存
```

## 边界情况

1. **空查询** → 返回空结果，不执行搜索
2. **超长查询** → 截断到 token 预算内
3. **无结果** → 返回空数组，不报错
4. **缓存安全** — 含变量的查询（如日期）不缓存
5. **模态检测** — 图片+文本混合查询自动路由到多模态搜索
