# ingestion — 策略与边界

> 摄入系统的去重策略、错误处理和边界情况。

## 去重策略

### 身份识别优先级
1. **content_hash** — 内容哈希完全匹配
2. **frontmatter ID** — frontmatter 中的 `id` 字段匹配
3. **slug** — 文件路径推导的 slug 匹配

### 去重规则
- 内容哈希匹配且未软删除 → 跳过（内容未变）
- 内容哈希匹配但已软删除 → **不**阻塞重新导入（允许重导）
- frontmatter ID 匹配 → 视为同一实体，更新内容

## 错误处理

```
单文件摄入失败
  → 记录到 failedFiles 日志
  → 不阻塞其他文件的摄入
  → 下次同步时重试

批量摄入失败
  → 部分成功的内容已写入
  → 失败的部分标记为待重试
  → 不回滚已成功的内容
```

## 边界情况

1. **重叠导入根目录** — 先导入 `/vault/Subdir/`，再导入 `/vault/`，通过去重检查避免重复
2. **slug 变化** — 文件移动后 slug 变化，但 content_hash 不变，通过去重更新
3. **软删除后重新导入** — 软删除的页面不阻塞同名新页面的导入
4. **大文件** — 超大文件自动切块，每块独立嵌入
5. **编码问题** — 自动检测文件编码（UTF-8、GBK 等）
