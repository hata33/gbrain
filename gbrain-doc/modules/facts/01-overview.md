# facts — 概述

> 事实系统是 GBrain 结构化知识的核心，从非结构化内容中提取可查询、可追踪的事实声明。

## 事实 vs 原始内容

| 维度 | 原始内容 | 事实 |
|------|----------|------|
| 格式 | 自由文本 | 结构化字段 |
| 精确度 | 模糊 | 精确（数值+单位） |
| 时效性 | 不明确 | 有时间戳 |
| 可追踪 | 困难 | 时间线追踪 |
| 用途 | 综合回答 | 指标查询、趋势分析 |

## 事实处理管线

```
原始内容
  → LLM 提取事实声明
  → 结构化为标准格式
  → 分类（metric / event / relationship / opinion）
  → 去重与合并
  → 写入 facts 表
  → 更新页面的 Facts 围栏
  → 可选：遗忘过时事实
```

## 与 Trajectory 的集成

事实系统与轨迹模块配合，支持：
- **指标时间线** — 追踪 MRR、用户数等指标的变化
- **Founder Scorecard** — 创始人四维评分（claim_accuracy / consistency / growth_trajectory / red_flags）
- **趋势回归检测** — 自动标记指标下降
